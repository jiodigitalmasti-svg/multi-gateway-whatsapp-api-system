DEVELOPER INTEGRATION

cPanel Deployment & Dual-Engine Microservices

How Bharat Web Solutions bridges cPanel shared environments with high-performance Node.js socket backends.

cPanel Setup Checklist
1
Node.js Application Manager

Open cPanel > "Setup Node.js App". Select Node v18+, upload gateway.js, and run npm install.

2
Deploy PHP Client Microservice

Place whatsapp.php in your public_html/api/ folder. Set $NODE_GATEWAY_URL to your local proxy port.

3
Configure Inbound Webhook Listener

Use webhook.php to capture inbound messages, status read receipts, and send automated transactional responses.

4
Multi-Gateway Round Robin

Assign separate SIMs to ports 3001, 3002, 3003, and 3004. High-traffic queues route automatically without throttling.

⚡ PHP SDK Integration (`whatsapp.php`) PHP 8.x Compatible

Call your WhatsApp microservice with native PHP cURL inside any WordPress, Laravel, or custom cPanel project: 

<?php
// Include Bharat Web Solutions WhatsApp API SDK
require_once __DIR__ . '/whatsapp.php';

$client = new BWSWhatsAppAPI([
    'gateway_url' => 'http://127.0.0.1:3000',
    'api_key'     => 'BWS_LIVE_KEY_84920491',
    'gateway_id'  => 'gw-alpha' // Alpha, Beta, Gamma
]);

$response = $client->sendMessage([
    'to'      => '919876543210',
    'message' => 'OTP: 842915 is your Bharat Web Solutions code.'
]);

if ($response['success']) {
    echo "Dispatched Message ID: " . $response['messageId'];
}
?>
